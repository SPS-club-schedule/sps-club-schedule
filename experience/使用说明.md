# SPS 经验档案

这里保存每一届 SPS 的交接材料、活动复盘和实用经验，面向所有人公开阅读。

推荐按照“届次 / 部门 / 主题”整理，例如：

```
2026-2027届/
  学术部/
    研讨班组织经验.pdf
  宣传部/
    海报制作经验.md
  联络部/
    场地预约流程.docx
```

以上只是目录示例，不代表已有这些经验材料。可以按实际需要创建其他文件夹。

登录 SPS 成员账号后，可以在网页创建文件夹、选择多个文件上传。资料立即公开；上传者可以移动、重命名、补充说明或收起自己的资料，收起后还可以恢复。网站维护管理和总管理员可以整理全部网页档案。

每份文件最多 10 MB，支持 PDF、Word、PowerPoint、Excel、Markdown、文本、图片和 ZIP/7z。请只发布适合公开的资料，上传前删去私人联系方式、账号密码等内容。

## 在线写作与公式

Markdown（`.md`）、LaTeX 公式（`.tex`）和纯文本（`.txt`）可以点“在线阅读”，无需下载。在线文档使用 UTF-8 编码，最多 256 KB；更大的文件仍可下载。

登录后点击“新建文档”，选择格式，在源代码区写作，旁边会实时预览。点击“保存并公开”发布；自己上传的资料可用“编辑正文”继续修改。退出前请保存，或下载源码保留草稿。如果其他人先保存了更新，系统会拒绝覆盖，请先保留自己的草稿，再重新打开最新版本。

Markdown 可以写标题、列表、表格和代码，也支持 LaTeX 公式：行内使用 `$E=mc^2$`，显示为 $E=mc^2$；独立公式用两行 `$$` 包围：

$$
\int_0^1 x^2\,dx=\frac{1}{3}
$$

`.tex` 文件可直接写公式、矩阵或 `aligned` 环境。这里提供公式预览；完整 LaTeX 文档仍需下载后使用 LaTeX 编译器生成 PDF。

仓库资料与其他成员资料可以“编辑并另存副本”，保存为自己的网页文档，不会覆盖原文。访客只能阅读和下载。

通过 GitHub 投稿的文件由仓库维护，网页上传的文件由档案服务保存，两者会显示在同一目录中。仓库资料在网站发布成功后出现；网页上传不会自动提交到 GitHub。

Agent 可以把文件放入本仓库的 `experience/` 目录并提交；具体方法见该目录的 `AGENTS.md`。网页上传的公开清单与文件也可通过 API 读取，便于整理与备份。
