# 管理员日常维护

管理员入口用于成员资料、账号协助、管理记录和归档恢复。普通成员仍可发布任务与维护共享模板；后台管理类型不等同于某项活动的负责人。

## 权限如何区分

成员页统一显示“管理员”，具体类型仅在后台和本人必要的权限界面使用。

| 管理类型 | 主要范围 |
| --- | --- |
| 部门管理 | 本部门下级成员的称呼、符合条件的密码重设；查看部门及全社团 DDL |
| 网页维护管理 | 下级成员的登录账号维护与管理日志、经验档案维护 |
| 总管理员 | 结合两类管理能力，可调整下级成员部门与管理类型 |
| 创始人 | 最高管理范围，包括总管理员任免与邀请码更换 |

任何类型都不能越级管理，也不能把本人当作下级目标操作。部门管理与网页维护管理不能相互管理。具体操作还受是否本人、是否跨社团账号以及版本检查约束，以服务端实际返回为准。

## 日常维护步骤

1. 确认正在管理正确社团，搜索目标成员并核对其称呼。
2. 打开编辑资料，修改自己有权限处理的字段。改称呼不等于改登录用户名。
3. 涉及用户名、任免管理类型或密码重设时，验证操作者自己的密码。
4. 保存后重新查看结果。若提示资料已更新，重新加载后再编辑，不用旧表单强行覆盖。

部门归属由总管理员或创始人调整。网页维护管理不能因为掌握账号维护权限就修改业务称呼与部门。

## 邀请与账号协助

只有管理员与创始人可查看和分享邀请入口；更换某个邀请码由创始人执行，对应旧链接失效，已有成员不受影响。

成员忘记密码时，优先让其使用恢复码。确需管理员协助时，为符合权限条件的目标签发一次性重设链接，由成员本人打开并设置新密码。链接只显示一次，有效 30 分钟；重新签发、相关角色变更等会使旧链接失效。不要把重设链接写入公开经验档案。

全站账号可能属于多个社团。目标已加入其他社团时，本社团管理员不能代改其全站用户名或生成重设链接；成员本人仍可在账号设置中操作。

## 恢复归档

进入“管理后台 → 归档恢复”，选择任务或模板，搜索并预览，再确认恢复。恢复主任务会带回当时随它归档的子任务；此前单独归档的步骤仍留在归档区。主任务尚未恢复时不能单独恢复子任务。

原负责人、完成记录、日期和时段保留，过期任务会继续显示逾期。恢复模板也不会修改已经发布的任务。

## 删除账号前理解结果

删除成员账号不可撤销，需要操作者密码和确认。不能删除自己、创始人或跨社团账号，也不能越级操作。

历史任务与完成记录保留，历史姓名显示为已离开的成员；未完成分工不会自动完成。同名重新注册得到新身份，不继承旧任务分配。这不是“暂时停用账号”，也不是“禁止再次注册”。需要重新安排工作时，应同时核对旧任务。

后台保留有限数量的近期管理记录，便于查看谁改了哪些字段，不记录密码与恢复码。处理问题时记录现象、操作时间和结果即可，不复制凭据。
