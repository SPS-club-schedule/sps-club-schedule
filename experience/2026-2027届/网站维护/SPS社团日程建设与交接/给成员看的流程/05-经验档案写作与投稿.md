# 经验档案写作与投稿

[社团经验档案](https://sps-club-schedule.github.io/sps-club-schedule/#/experience)公开可读。SPS 成员登录后可以投稿，访客可以搜索、在线阅读和下载。这里适合保存实际做过的流程、活动复盘和交接材料。

## 把经验放在哪里

采用“届次 / 部门或工作职责 / 主题”。例如本系列在“2026-2027届 / 网站维护 / SPS社团日程建设与交接”，再区分成员流程和 agent 维护文档。这里的“网站维护”是资料归类，不会新建账号部门。

发布前先搜索同主题，更新自己的旧文档或补充明确的新部分。网页文件和仓库文件同名也不会互相覆盖，重复上传会让后来的成员难以判断应读哪份。

## 在网页新建文档

1. 进入目标目录，按需新建文件夹。
2. 点击“新建文档”，选择 Markdown、LaTeX 公式或纯文本。
3. 写源文，检查旁边预览，再点“保存并公开”。
4. 返回目录重新打开，确认正文与路径正确；需要交接时分享该文档的在线链接。

Markdown 适合大多数经验：标题、步骤、表格、代码和公式都能使用。在线阅读上限为 UTF-8 256 KiB。LaTeX 入口预览公式、矩阵等，完整论文式 TeX 工程仍需要下载并单独编译成 PDF。

未保存的编辑可能因关闭页面或手动刷新丢失，可先下载源码留存。保存失败时保留草稿；版本冲突时应先保留自己的文字，重新读最新版本后再整理。

## 上传已有文件

可多选上传 PDF、Office 文档、表格、Markdown、文本、位图和 ZIP/7z 等允许格式；单文件最多 10 MiB。上传前删去私人联系方式、账号密码、恢复码、邀请链接和不适合公开的成员信息。内部工作材料不应因为目录名写着“agent”就当成私密。

自己的网页资料可移动、重命名、补说明、收起或恢复。维护者可按权限整理全部网页资料。收起后不再公开，但仍保存内容并占空间。

## 修改正文与另存副本

自己上传的在线文档可“编辑正文”。仓库文档和没有编辑权限的他人文档，可“编辑并另存副本”，成为自己的独立网页资料，原文保持不变。

网页上传保存在网站后端，不会自动进入 GitHub。仓库投稿通过 Git 提交与 Pages 发布后出现；修改仓库文档应走仓库维护流程。这套系列采用仓库投稿，因此日后在网页另存的副本不会自动修正本系列原稿。

## 推荐写法

一份有用的经验可以回答五件事：

1. 适用于什么活动、哪一届、哪种角色。
2. 具体做过什么，按什么顺序，交付物是什么。
3. 哪一步遇到问题，观察到什么现象，怎么解决。
4. 哪些方法已经验证，哪些还在尝试。
5. 下一位接手者应先做什么，参考资料在哪里。

例如“海报依赖文案”还不够，可以补充文案需含哪些信息、谁确认、多久前交付，以及文案改动后如何通知海报负责人。涉及测试、费用或服务限制时附日期，不把旧数据当成永久结论。
