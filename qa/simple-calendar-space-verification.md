# 极简日历滚动与邮件提示

2026-11-06（北京时间）。网站与内置前端 Android 1.6.1 / code 8 共用本次修改。

## 修改

- 顶部页面标题、提示、日历工具、预约状态及 DDL 区放进同一个滚动容器；向下滚动时随时间轴收起，向上滚动时重新出现。初次打开仍定位到 08:00。
- 长按和双指缩放只作用于时间格，不拦截顶部按钮、日期输入或 DDL 点击。缩放按时间格的实际偏移保持中心时间，手指离开后的延迟滚动事件也不改变顶部栏状态。
- 邮件建议增加带可访问名称的 ×。关闭提示不发起邮件设置写入；关闭、保留或成功停用后按账号保存当前浏览器/App 的已处理状态。账号设置中的邮件开关继续可用。

## 验证

- `npm test`：212 项通过；修改后的日历界面及手势专项 12 项复查通过。
- `npm run test:worker`：80 项通过；`npm run test:gateway`：4 项通过。
- `npm run test:guides`：桌面、手机及内置 App 页面共 31 项通过，2 项仅适用于网站的缓存 HTML 测试在 App 项目中按原规则跳过。
- 使用隔离的浏览器上下文和虚构账号检查 1440×900、390×844、390×792 三种尺寸。向下滚动 560px 后顶部栏完全离开视野，反向滚动恢复；无横向溢出和页面异常。手机样例在建议尚未关闭时，时间轴可见高度从约 392px 增至 803px。
- 点击 × 后刷新及往返设置均保持隐藏，未更改邮件开关；从设置关闭、再开启邮件提醒均成功，返回日历仍不重复提示。浏览器验证使用拦截接口，没有修改生产账号或发送邮件。
- 手机和 App 尺寸使用 Chromium 触控协议检查单指滑动、双指缩放，缩放中心时间偏差小于 0.1 个 15 分钟格。截图保存在忽略的 `qa/simple-scroll-*.png`。
- 生产配置网站构建、Android `testDebugUnitTest lintRelease assembleRelease` 及 `git diff --check` 通过。APK v2 签名有效，证书与 1.6.0 一致，包名不变、版本号递增，可覆盖升级；ZIP 内仅含 APK 和安装说明。

本次未在实体手机重新验收；浏览器的 App 尺寸验证不等同于厂商 WebView 实机验证。已安装的 App 需要安装 1.6.1 才会获得新的内置页面。
