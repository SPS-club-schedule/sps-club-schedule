# 共享任务模板验证

2026-10-30。保持现有 GitHub Pages + Leafuke Cloudflare 网关与原 SQLite Durable Object；在通用 records 表中增加 templates 集合，不替换已有数据库或任务。

- 每个社团初始化一个可编辑的研讨班模板，包含提前4/3/3/2/1天的五个步骤。已有社团首次读取时在事务内初始化一次。
- 任意成员创建、复制、编辑、分类和使用本社团模板；模板归档限模板创建者和社团创建者。跨社团引用与越权访问被拒绝，模板编辑使用 revision 防止并发覆盖。
- 选择模板产生独立草稿，支持修改标题、说明、负责人、完成方式、优先级、提前天数、顺序和具体日期。更换主任务日期只重算相对日期。过期日期或晚于主任务的日期不能发布。
- 主任务和全部子任务在一个事务内写入，只有一个同步版本；失败全部回滚，重复请求返回已有任务，过期后重试与归档后重试不会重新创建任务。
- 模板修改和归档不改变已发布任务。任务与模板分别按版本合并增量同步与归档标记，晚到的写入确认不会复活归档记录。

自动验证：52项领域/同步/日历/模板测试、13项真实 Workers/SQLite 集成测试、3项网关测试。新增覆盖包括日期推算、手动日期保留、模板共享与分类、权限和跨社团检查、版本冲突、无效输入、事务中途失败、重试、重启持久化、模板与任务隔离、XSS 转义和缺失模板错误页面。
