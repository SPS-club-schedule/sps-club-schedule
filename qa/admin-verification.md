# 成员与账号管理验证

日期：2026-10-30。

- 新增管理后台，创建者作为初始管理员并可任免其他管理员。普通成员无入口，直接访问管理网址显示权限不足；管理 API 独立检查当前社团和当前角色。
- 54项 JS 测试、20项 workerd/SQLite 集成测试、3项网关测试通过。覆盖跨社团权限、用户名唯一性与事务回滚、过期表单、创建者保护、角色任免、密码确认限流（失败不能回滚限流计数）、单次重设链接/轮换、旧恢复码及会话失效、多社团账号保护，以及 runtime 重启持久化。

- 新增表采用幂等创建；不改变现有生产账号字段、DO 绑定或数据库位置。密码重设继续复用已有网关路径 `/auth/recover`。
