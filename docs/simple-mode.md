# 极简日程与统一 Android App

极简模式与完整模式共用账号、社团和任务数据。浏览器中，完整页面导航的「极简模式」进入 `#/simple`，右上角「完整模式」切回；App 使用顶部原生模式按钮。网站和 App 首次默认极简模式，按设备记住之后选择的模式；退出登录或重新打开后继续使用该模式。

## 使用

- 未登录可直接浏览物院社团预约的公开日历，点击右上角「登录」后回到极简日历，加载本人可访问的任务。游客不会请求私人任务或账号偏好接口，也不会显示创建、编辑、负责人或邮件设置。
- 点击「完整模式」时若未登录，先登录再进入完整模式；登录页提供「先看日历」返回入口。已登录的任务权限不变。

- 只呈现日历，支持日、3天、周视图。DDL 在顶部，持续日程在时间轴中。包含已完成任务，但不显示完成、逾期、优先级或层级状态，也没有完成按钮。
- 叠加物院社团预约的公开活动时段，以暖黄色显示社团和活动名；点击查看起止时间、地点，并可进入预约网站。只读预约不提供编辑、移除或完成按钮。预约跟随日程同步刷新，也可点「更新」；网络失败时保留上次结果并提示。公开窗口为北京时间今天至两个月后的对应日期（含），不含课程。
- 预约覆盖所有任务范围，手动创建的 SPS 预约同样显示。从日程同步过去的预约，仅当当前视图已经有对应任务时段且覆盖预约时间时去重；例如「我的日程」仍能看到其他成员活动占用的时段。主讲人继续仅查看被分配任务。数据由同一后端提供，预约变化无需更新 APK；App 的界面更新从 1.4.0 起通过新版 APK 发布。
- 鼠标直接拖动空白时间轴；手机先长按 330ms，再上下拖动创建时段。单指直接滑动滚动；双指缩放纵向格距，始终保持 15 分钟一格。也可用「新建」和「＋／−」按钮。键盘聚焦日期列后按回车可新建。
- 创建表单只有大标题、小标题、开始、结束、负责人。时间按北京时间解释。开始等于结束为 DDL，结束早于开始会拒绝；持续时段以结束时间作为截止时间。
- 日历里点击日程查看标题、时间和负责人；有管理权限的人可以编辑或移除。删除大标题的独立日程会同时归档其下全部子任务，确认框明确列出数量；管理员可恢复。

## 与原任务的对应

同一社团内，大标题按完整字符串匹配；忽略首尾和重复空白、英文字母大小写及全半角差异，不做模糊匹配。小标题不为空时，新日程是匹配主任务的子任务。若已有多个同名主任务，必须选择具体归属；不会任意选择。归档任务不参与匹配。

找不到主任务时，服务端在一个事务中建立大标题分组与子任务。分组标记 `simpleContainer`，在完整模式中作为主任务出现，但极简日历不为它虚构一条独立日程，也不为它发送任务邮件。后来以同一大标题、小标题留空创建日程，会将可管理的分组提升为真正主任务并保留原子任务。若同名主任务已有独立日程，提示编辑原任务或填写小标题，防止误建重复主任务。

每次创建都有请求 ID。并发创建同名标题在同一 Durable Object 事务内匹配；网络重试不会重复创建主任务或子任务。分组提升使用 `simpleRequests` 保存请求回执。

社团部员可以给现有大标题追加自己创建的子任务；这不授予修改主任务或他人子任务的权限。原主任务创建者和社团创建者继续保留管理子任务的权限。主讲人权限仍为查看自己被分配的任务。极简日历范围沿用现有账号角色与部门策略。

子任务现在也能保存持续时段；完整模式编辑器与日历同时支持。预约推送明确排除子任务、分组和 DDL，只同步未归档且具有持续时段的主任务。旧任务不需要迁移。

## 邮件偏好

每个账号的「账号设置 → 邮件提醒」开关保存于服务端 `account_preferences`，默认开启，适用于所有社团。

进入极简模式时，若提醒仍开启，自动提示关闭，提供「关闭提醒」和「保留提醒」。不会未经选择就更改偏好；提示不会显示已关闭提醒的账号。

关闭后取消该账号尚未发送的任务邮件，停止分配、截止前、到期和依赖提醒。部门升级提醒只汇总仍开启提醒的逾期成员；关闭者不会出现在部门负责人的新提醒或重试内容中。若同一任务仍有其他开启提醒的逾期成员，负责人仍可收到那些成员的提醒。负责人自己关闭提醒时，也不会收到升级邮件。验证码不受该开关影响。已投递的邮件无法撤回。

## Android

从 1.3.0 起统一为「SPS 社团日程」，包名 `org.spsclub.schedule`，不再分发两种新版本。App 顶部提供模式按钮，选择「极简模式 / 完整模式」。首次默认极简，之后保存到独立的原生 SharedPreferences；网页内切换也会通过限定来源的消息桥同步该偏好。会话过期、退出登录和清理登录缓存不重置模式。

沿用原 App 的 WebView 安全边界、加密会话、可选记住密码、文件选择及下载。模式选择只允许 `simple` / `full` 两个值，不改变权限；完整页面仍由网页和后端要求登录。尚未保存的编辑在通过原生按钮切换时会提示确认。

原完整版 1.0–1.2 及统一版 1.3–1.5 可用相同签名覆盖安装 1.6.0，保留本机登录与模式选择。旧独立极简版 `org.spsclub.schedule.simple` 是不同包名，需安装统一版并重新登录；服务器账号与任务不用迁移，之后只需使用统一版。

```sh
cd android
./gradlew testDebugUnitTest lintRelease assembleRelease
```

签名仍由仓库外的 `SPS_ANDROID_SIGNING_PROPERTIES` 配置提供。当前成品为 `public/downloads/SPS-Schedule-1.6.0.apk` 和 Windows 兼容的同名 ZIP。网站的游客日历及登录页均有统一 App 下载入口，旧下载 URL 仍保留。

1.4.0 将页面、脚本、样式、字体和仓库档案内置在 APK 中，直接请求原有任务与预约后端。无需下载前端即可显示界面；自动登录在界面显示后进行，不阻塞游客日历。App 隐藏下载、分享包和网页的模式切换按钮，只保留顶部原生选择器。1.5.0 同时取消极简日程重复的标题栏，将登录和账号设置移到日历工具栏；网站保留原入口。

1.5.0 打开时先显示上次成功缓存的任务和预约，再联网刷新。任务缓存按账号及社团隔离，退出账号清除私人缓存；服务端删除或撤回权限后同步更新。断网保留上次内容并提示状态，任务与预约更新仍需联网，不提供离线编辑或后台推送。App 的界面修改需要安装新版 APK。离线启动和模式重开恢复已在 Android 模拟器验证；不同厂商实体手机的长按、双指缩放仍需验收。
