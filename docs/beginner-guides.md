# 任务与经验档案指南

2026-11-05 校订，网站与内置前端 App 1.6.0 共用实现。指南位于完整模式，保留既有按账号/社团保存的跳过与完成记录，不强制让已完成者重新走一遍。

- 成员入口：工作台、任务编辑器和档案目录中的「新手指南」。完整流程 27 步，从对应页面重开时可从相关步骤开始。
- 管理员入口：模板库「管理员指南」（原「模板设置教程」）。完整流程 37 步，部门管理员仍可按原规则自动收到引导。

成员指南以待办完成、详情入口、已完成分类、任务草稿、时段/截止和子任务负责人为主线；管理员先学习共享模板、角色、依赖、倒排和套用。两者均包含经验档案的搜索、在线阅读、既有文档编辑/另存副本、上传、目录、新建文档、预览、格式、路径与发布入口。预约总览和 ICS 导出不再是必经步骤。

## 控件与说明

- 完成步骤直接高亮 `.todo-toggle`，不再高亮「我的待办」标题；真实点击按原任务权限完成，不自动代操作。
- 名称、完成方式、角色、依赖、倒排按钮和文档源码分别定位实际输入框、选择器或按钮，不用整张表单代替缺失目标。
- 空待办、空模板库、无可预览档案、无档案写权限均显示对应说明。找不到预期控件时保留说明卡、重新定位、上一步与跳过，避免静默隐藏。
- 返回子任务步骤会重新展开对应面板。窄屏和键盘视口变化时重定位目标，提示卡滚动，较大的字段组在高亮区域内滚动；不会将高亮裁到不相关的底部按钮。
- 任务发布与文档保存步骤不可提交。教程捕获相关表单提交，管理员练习另有原业务层保护。文档编辑/上传/建目录入口步骤为位置说明，不自动写入或弹出文件选择器。
- 通过指南跨页时任务/文档草稿在当前页面会话内暂存；返回可恢复。正常离开未保存文档仍要求确认；刷新或关页会丢失未提交草稿。

## 回归检查

`npm run test:guides` 使用 Playwright 的真实浏览器运行三组页面：桌面网页、手机网页、App 编译版本（扣除原生工具栏高度）。每组走完两套指南并检查目标存在、可见、高亮与说明卡不重叠，还覆盖真实完成操作、空列表、只读档案、上一步、缺失目标和键盘大小视口。

测试使用独立本地静态服务与拦截的虚构 API；任何未匹配的外部请求均拦截。除专门验证用户主动完成的用例外，两套指南全程断言没有任务、模板或档案写入。CI 在发布网站前执行；浏览器安装命令为 `npx playwright install --with-deps chromium`。失败保留截图与 trace。

关键代码：`client/member-tutorial.js`、`client/department-tutorial.js`、`client/onboarding.js`。调整界面时应同步检查选择器和文案，继续用空列表与手机布局验证，不能用任意容器作通用后备高亮。
