# 电脑工作区与内部管理权限（2026-10-30）

## 页面行为

宽度至少1000px使用左侧导航、窄工作台、右侧展开区。工作台内容与编辑器/日历分别滚动，不提供左右拖动。窄屏隐藏后台的工作台副本，编辑任务、模板或打开大日历时呈现独立页面。日历可在电脑上保留，点击任务后详情在窄工作台显示；编辑器优先占用右侧空间，保存后返回详情。

大日历支持日/周切换、选日期、上/下日或周、今天、展开某一天；时间统一为北京时间。持续活动按起止时间绘制，重叠分栏，跨午夜逐日切分；截止事项使用细条，可整体关闭。其他社团活动沿用预约服务的公开活动接口，不读取课程。预约系统的展示日期范围不变。个人 ICS 导出仍只包含操作者负责的活动与截止事项。

日历权限是显示范围；任务看板及任务详情仍是原有的社团共享资料，不把日历筛选描述为数据保密边界。

## 内部管理类型

| 内部值 | 仅后台显示 | 成员管理范围 | 登录用户名 | 称呼 | 密码重设 | 日历截止范围 | 管理日志 |
|---|---|---|---|---|---|---|---|
| `member` | 成员 | 无 | 本人账号设置 | 本人成员页 | 本人恢复流程 | 自己 | 无 |
| `department_admin` | 部门管理 | 本部门普通成员 | 无 | 管理范围内 | 管理范围内 | 默认本部门，可选各部门/全社团 | 无 |
| `web_admin` | 网页维护管理 | 全社团普通成员 | 管理范围内 | 无 | 管理范围内 | 自己 | 可看 |
| `admin` | 总管理员 | 低于自己的管理类型及成员 | 管理范围内 | 管理范围内 | 管理范围内 | 默认全社团，可选部门/自己 | 可看 |
| `owner` | 创始人 | 所有低于自己的成员 | 管理范围内 | 管理范围内 | 管理范围内 | 默认全社团，可选部门/自己 | 可看 |

同级、跨管理类型的两种同级管理员、自己均不能通过管理接口管理；本人使用账号设置和成员称呼表单。只有总管理员与创始人可调整部门与任免下级管理类型；部门管理必须指定部门。部门管理的后台列表仅返回其所在部门成员；普通成员无法读取管理类型、账号列表、日志。

所有管理类型在普通成员页均标为“管理员”，包含创始人。公开 bootstrap/delta 成员列表仅保留本人真实类型以供自己的权限界面使用，其他管理员统一投影为 `admin`；完整内部类型只在鉴权后的后台返回。角色/部门发生变化后立即清空后台缓存、重新计算截止范围；服务器重新校验所有写入。

原有账号删除保护继续有效：不能删除本人或创始人，跨社团账号不能由本社团接管，必须验证操作者密码和成员/账号版本。重设链接在签发人或目标调换部门、改变类型后撤销；使用时再次检查权限。邀请和归档恢复沿用管理员入口及原有服务端校验。

## 兼容与发布

不新增数据库，不修改 Durable Object 名称/绑定，不更换账号或社团 ID。已有 `admin` 解释为总管理员，其原有成员/账号管理能力保留；此次部署不替用户任免任何真实成员。先部署原 SPS Worker，再由原 GitHub Pages 工作流发布前端。预约服务无需变更。

验证包括105项单元/界面/领域测试、45项 workerd/SQLite 集成测试、3项网关测试；新增检查管理类型互斥与层级、跨部门拒绝、字段越权、重设链接撤销、公开类型隐藏、日历范围降权、截止隐藏、重叠时段和午夜边界。真实本地 Worker 浏览器验收覆盖电脑并排任务保存、模板编辑、手机390×844独立页面、普通成员与部门管理日历范围，以及公开成员页隐藏内部类型。
